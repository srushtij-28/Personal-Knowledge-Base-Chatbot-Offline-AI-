# 🤖 Personal Knowledge Base Chatbot 

## 💡 Overview
The **Personal Knowledge Base Chatbot** is an offline Python application that allows users to store their own notes and ask questions about them.

It works like a **mini ChatGPT for your personal documents**, retrieving relevant information from stored text without using the internet or any AI APIs.

---

## 🚀 Features

### 📚 Knowledge Storage
- Users can paste any notes, articles, or text
- Information is indexed and stored in memory

### ❓ Question Answering
- Ask questions about your notes
- The bot retrieves relevant sentences

### 🧠 Keyword-Based Matching
- Uses word matching and indexing
- Returns the most relevant stored sentence

### 🌐 Fully Offline
- No APIs
- No internet required
- No cloud services

---

## 🧠 Concepts & Technologies Used
- Python
- Text parsing
- Keyword indexing
- Information retrieval
- Chatbot logic
- CLI-based conversational systems
